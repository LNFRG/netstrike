# NETSTRIKE

**Понятный интерфейс для [zapret](https://github.com/Flowseal/zapret-discord-youtube): обход блокировок Discord и YouTube в один клик и оптимизация Windows для игр.**

Без командной строки и ручного перебора `.bat`-файлов: программа сама подберёт рабочую стратегию, включит обход вместе с Windows и будет следить, чтобы он не отваливался.

### [⬇ Скачать последнюю версию](https://github.com/LNFRG/netstrike/releases/latest)

Нужен файл `NETSTRIKE-Setup-<версия>.exe`. Дальше программа обновляется сама.

---

## Что умеет

### Обход блокировок
- **Старт / Стоп одной кнопкой.** Обход работает в фоне, окно можно свернуть в трей.
- **Автоподбор стратегии.** Программа по очереди пробует стратегии zapret и оставляет ту, с которой открываются нужные сайты. Кнопка «Проверить все» покажет результат каждой.
- **Адаптивная настройка.** Напишите обычными словами, что должно работать — например, «Discord и YouTube, играю в Valorant», — и программа подберёт фильтры, списки сайтов и стратегию. Для Discord проверяется и голосовой чат, а не только сайт.
- **Автозапуск с Windows** — обход включается сам при загрузке компьютера.
- **Сторож.** Если обход неожиданно упал, программа поднимет его снова и сообщит об этом.
- **Свои сайты.** Не открывается какой-то сайт — проверьте его в «Инструментах» и добавьте в обход одной кнопкой.

### Инструменты
- **Проверка домена** — открывается ли сайт и обходится ли он.
- **Игровые серверы** — пинг до регионов CS2, Dota 2, Valorant и Apex Legends.
- **Диагностика** — находит то, что мешает обходу: VPN, другие программы того же рода, проблемы с драйвером.

### Оптимизация для игр
- **Анализ ПК** за пару секунд: процессор, видеокарта, память, диски.
- **Только настройки, которые реально влияют на игры:** частота монитора (частая беда — монитор на 144 Гц работает на 60 Гц), план питания, запись Xbox Game Bar, акселерация мыши, видеокарта для игры на ноутбуке и другие. У каждой — честная оценка эффекта.
- **Всё обратимо.** Перед любым изменением сохраняется исходное значение, у каждого пункта есть «Вернуть как было», а также «Вернуть всё».
- **Автозагрузка и фоновые программы** — что запускается вместе с Windows и что занимает память.
- **Советы по железу** — например, если память работает без профиля XMP или игры стоят на HDD. Программа ничего не меняет в BIOS, только объясняет.
- **Место на диске** — очистка временных файлов, дампов и кэшей; список игр Steam по размеру и дате последнего запуска.

## Установка

**Нужно:**
- Windows 10 или 11, 64-бит;
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/ru-ru/download/dotnet/8.0) (раздел «.NET Desktop Runtime», Windows x64) — если программа не запускается, поставьте его.

1. Скачайте `NETSTRIKE-Setup-<версия>.exe` со [страницы релизов](https://github.com/LNFRG/netstrike/releases/latest) и запустите.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**. Предупреждение появляется потому, что у программы пока нет платной цифровой подписи.
3. Путь установки по умолчанию — `C:\NETSTRIKE`. Не ставьте в папку с русскими буквами или пробелами: обход в таких папках может не заработать.
4. При первом запуске программа спросит, что должно работать, и настроит всё сама. Можно пропустить — тогда она просто подберёт стратегию для Discord и YouTube.

**Обновление** — автоматическое: новая версия скачивается в фоне, а ставится по кнопке «Перезапустить и обновить», чтобы не прерывать игру. Если у вас версия 1.1.0, один раз установите новую поверх — настройки сохранятся.

## Почему нужны права администратора

Zapret работает через драйвер WinDivert, а автозапуск — через службу Windows. Без прав администратора ни то, ни другое не работает, поэтому программа всегда запрашивает их при запуске.

## Что программа делает с системой

- **Ничего не меняет без нажатия.** Оптимизации и очистка — только по кнопке и после подтверждения со списком изменений.
- **Не отправляет никаких данных о вас.** Своих серверов у программы нет. В сеть она обращается только:
  - к GitHub — проверить обновления NETSTRIKE и zapret, скачать списки сайтов;
  - к сайтам, которые проверяет (Discord, YouTube и те, что вы добавили сами), — чтобы понять, работает ли обход;
  - к серверам Discord (`latency.discord.media`) — проверить голосовой чат;
  - к дата-центрам Amazon — замерить пинг для «Игровых серверов».
- **Обновления проверяются.** Новая версия скачивается только из релизов этого репозитория и сверяется по контрольной сумме SHA-256.
- **Папка программы закрыта от записи** обычными пользователями — чтобы никто не мог подменить файлы, которые запускаются с правами администратора.

## Удаление

«Параметры → Приложения → NETSTRIKE → Удалить». Удаление само остановит обход, уберёт службу автозапуска и драйвер, а если вы меняли настройки в «Оптимизации» — предложит вернуть их как было.

## Частые вопросы

**Антивирус ругается на WinDivert64.sys или winws.exe.**
Это компоненты самого zapret: драйвер перехватывает сетевой трафик, поэтому часть антивирусов помечает его как подозрительный. Если доверяете — добавьте папку программы в исключения антивируса.

**Сайт всё равно не открывается.**
Проверьте его в «Инструменты → Проверка домена» и добавьте в обход. Если не помогло — запустите автоподбор: для разных провайдеров работают разные стратегии.

**Discord открывается, но голос висит на «Подключение…».**
Запустите «Адаптивную настройку» с запросом «Discord» — она подберёт стратегию с проверкой голосового чата. Если не помогает — «Инструменты → Сбросить WinDivert» и отключите VPN, если он включён.

**Где журнал, если что-то сломалось?**
`%LOCALAPPDATA%\NETSTRIKE\logs` — пришлите эти файлы вместе с описанием проблемы.
